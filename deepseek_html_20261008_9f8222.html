Installation Wizard
AWEWEBOS-ը իրական վեբ օպերացիոն համակարգ է։ Ամբողջ ֆայլային համակարգը կտեղադրվի ձեր ընտրած պանակում, և բոլոր փոփոխությունները իրականում կգրանցվեն այնտեղ։
1
Ընտրեք տեղադրման պանակ
Սեղմեք ներքևի կոճակը և ընտրեք դատարկ պանակ ձեր համակարգչում (օրինակ՝ Desktop/AWEWEBOS)։ Այստեղ կտեղադրվեն OS-ի բոլոր ֆայլերը։
2
Հաստատեք թույլտվությունը
Բրաուզերը կհարցնի թույլտվություն՝ կարդալու և գրելու այդ պանակում։ Սեղմեք «Edit files» կամ «Խմբագրել ֆայլերը»։
3
Տեղադրում
AWEWEBOS-ը կստեղծի հետևյալ կառուցվածքը․
AWEWEBOS/ ├── System/ // Kernel & config │ ├── kernel.json │ ├── config.json │ └── users.json ├── Users/ │ └── user/ │ ├── Desktop/ │ ├── Documents/ │ ├── Pictures/ │ ├── Music/ │ └── Downloads/ ├── Apps/ // Installed apps ├── Themes/ // Theme files └── Settings/ └── preferences.json
⚠️ Ձեր բրաուզերը չի աջակցում File System Access API-ն։ Խնդրում ենք օգտագործել Chrome, Edge կամ Opera վերջին տարբերակը։
